# Руководство по ручной разметке

Размечайте обращение по содержанию сообщения игрока. Не считайте обвинение доказанным фактом. Не смотрите на прогноз модели до заполнения меток.

## Категории

| Код | Значение |
|---|---|
| `complaint.insult` | Оскорбления и токсичность |
| `complaint.cheat` | Читы и стороннее ПО |
| `complaint.dm` | Убийство/урон без повода, DM, нарушение RP или правила зелёной зоны |
| `complaint.scam` | Обман и мошенничество с игровым имуществом |
| `complaint.rmt_ads` | Продажа/реклама за реальные деньги, RMT |
| `complaint.admin` | Жалоба на администратора |
| `complaint.other` | Другое предполагаемое нарушение |
| `complaint.invalid` | Это не жалоба, недостаточно содержания или некорректный формат |
| `report.question` | Вопрос по механике игры |
| `report.help` | Просьба о помощи: баг, застрял, телепорт и т. п. |
| `report.complaint` | Жалоба на игрока через канал репорта |
| `report.account` | Доступ к аккаунту, взлом, пропажа имущества |
| `report.payment` | Платёж, донат, покупка не зачислилась |
| `report.offtopic` | Оффтоп, приветствие, пустое сообщение |

## Приоритеты

| Код | Значение | Ориентир из таксономии |
|---|---|---|
| `p0` | Критично | Взлом/потеря доступа, платежи, массовый баг, угрозы вне игры |
| `p1` | Высокий | Читы, крупное мошенничество, RMT, жалоба с доказательствами |
| `p2` | Обычный | Оскорбления, DM, нарушения RP, вопросы по правилам |
| `p3` | Низкий | Вопросы по механике, предложения, оффтоп, жалобы без доказательств |

## Правила

1. Для каждой строки заполните `category` и `priority` строго кодом из таблиц.
2. Не выводите категорию только из `images_count`: вложение не доказывает нарушение.
3. Если текста недостаточно, используйте `complaint.invalid` для жалобы или `report.offtopic` для пустого/непонятного репорта.
4. Если жалоба содержит несколько нарушений, выберите основную проблему, на которую направлено обращение.
5. Приоритет определяйте независимо от категории: например, платёж — `p0`, даже если текст очень короткий.
6. В `reviewer_notes` кратко объясните спорные решения или неоднозначность.
7. Если не можете определить метку, оставьте поле пустым; скрипт оценки пропустит эту строку.

Категории и приоритеты взяты из `backend/data/taxonomy.json` (черновик задания). Если организаторы обновят таксономию, следуйте утверждённой версии.
